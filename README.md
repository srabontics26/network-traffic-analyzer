# Network Traffic Analyzer

A simple Python-based tool for checking basic network information and analyzing sample network traffic data.

## About the Project

This project was created to practice Python networking concepts and understand how basic network information can be collected and displayed.

The program shows the computer hostname, local IP address, current time, protocol statistics, and IP addresses for selected websites.

## Features

- Display local hostname
- Find local IP address
- Show current date and time
- Display protocol statistics
- Resolve website hostnames to IP addresses
- Handle network resolution errors
- Simple command-line interface

## Technologies Used

- Python 3
- Socket module
- Collections module
- Datetime module
